## How to add your own screenshots

1. Use your system's screenshot tool (Snipping Tool on Windows, Cmd+Shift+4
   on Mac, Print Screen on Linux).
2. Capture the terminal showing `mistake-box` output, pytest results, or
   your AI agent using the skill.
3. Name it something descriptive, e.g.:
   - `cli_error_box.png`
   - `pytest_failing_test.png`
   - `agent_code_review.png`
4. Drop the PNG into this folder.

## Tips

- Show real usage — actual error boxes, actual test output, actual agent
  conversations.
- Cover different scenarios: syntax errors, runtime errors, test failures,
  code review findings.
- Captions are not required but a descriptive filename tells the story.
