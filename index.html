What does it do?

Two tools in one — instant error reports for your terminal, plus an AI-agent skill for deeper analysis.

🔴→🟢

Fix Failing Tests

When your tests turn red, the AI-agent skill investigates every failure in parallel, finds the root cause with file and line evidence, and proposes minimal fixes — rolling back anything that doesn't work, and stopping for human review when it cannot auto-repair.

🔍

Review Your Code

Six parallel checks look for logic errors, security issues, missing error handling, concurrency bugs, resource leaks, and test gaps — all with file:line evidence or the finding is not reported.

📦

Friendly Error Boxes

Run any Python file through mistake-box and get a clear, human-readable report showing WHERE the mistake is, WHAT went wrong, and HOW TO FIX it — instead of a confusing raw traceback.

🧪

pytest Plugin

Install once with pip install . and every pytest run automatically shows failing tests as friendly boxes. No configuration needed. Disable with --no-mistake-box.

🎓

Built for Learners

14 demo files with intentional mistakes help you practice reading error messages. Each demo shows the wrong code, the error explained, and the correct version — a ready-made learning lab.

Two ways to use it

A CLI tool for instant feedback. An AI-agent skill for deep analysis. Both in one package.

1. As a CLI tool and pytest plugin

Install once and get instant error reports in any terminal:

$ pip install . # one-time install
$ mistake-box python mycode.py # run and box errors
$ pytest # auto-box every failing test

The mistake-box command wraps any Python command, catches errors, and prints a friendly box instead of a raw traceback. The pytest plugin does the same for test failures automatically.

2. As an AI-agent skill

Give the skill to any AI coding agent and ask it to find and fix mistakes:

You: "Run mistake-finder on the failing tests"
You: "Check my code for mistakes"
You: "Review src/myfile.py for mistakes"

The skill (SKILL.md) works with any AI coding agent — Claude Code, Cursor, Codex, ChatGPT Codex, Devin, or any agent that can read files, run commands, and edit files. No vendor lock-in. No IDE required.

Get started in 3 steps

Works on Windows, Mac, and Linux. No experience needed.

Install Python (if you don't have it)

Download Python 3.8+ from python.org/downloads. On Windows, check "Add Python to PATH" during installation. Verify with python --version.

Install the tool

Clone the repository (or download the ZIP), open a terminal in the project folder, and run pip install .. This installs the mistake-box command and the pytest plugin.

Start finding mistakes

Run mistake-box python mycode.py to check a file. Or run pytest to see failing tests boxed automatically. Try the demo files in demos/ to practice.

Try the demo files

The demos/ folder has 14 Python files, each with one intentional mistake. Run them and read the box to learn what different errors look like:

The AI-agent skill

A skill file that teaches any AI coding agent how to find and fix mistakes systematically.

📄

SKILL.md — The brain

The skill instruction file. Defines two modes (failure triage and code review), a four-phase workflow, and guardrails that keep the agent safe and evidence-based.

📋

review-checklist.md — Six check classes

Logic & boundaries, error handling, concurrency & state, resource & performance, security footguns, and test gaps. Each class is a separate investigation pass.

📊

report-template.md — Consistent output

Exact formats for ranked reports in both modes. Every finding includes file:line evidence, severity, confidence, and a suggested fix.

How to give the skill to your AI agent

The skill lives in .bob/skills/mistake-finder/. Tell your agent:

"Read the file .bob/skills/mistake-finder/SKILL.md and follow its
instructions for this task."

$ python install_skill.py # install globally

$ python install_skill.py --remove # uninstall

Technical details

What's inside the package and how it's built.

🔒

Safe by design

Investigating agents are read-only. Tests are never weakened or deleted. Every finding needs file:line evidence. One fix at a time, with full rollback. The core tool runs entirely on your computer — no API keys, no cloud services, no data leaves your machine.

📦

Installable package

pip install . registers two entry points: the mistake-box CLI command and the pytest11 plugin. Works in any Python interpreter — VS Code Testing panel, PyCharm, terminal, CI.

🌐

IDE-agnostic

No dependency on any specific editor, AI provider, or cloud service. The skill works with any AI agent. The CLI works in any terminal. The pytest plugin works with any IDE that uses pytest.
